# 灰烬环线可玩演示关卡

## 入口

- 桌面高画质：`/?fixture=campaign-demo&quality=high`
- 手机与低动效：`/?fixture=campaign-demo-reduced&quality=low`

## 玩家旅程

1. 进入场景时，七职业玩家混编部队已经选中，命令栏立即可用。
2. 玩家基地拥有联网供电的兵营、工厂、后勤节点和前线哨戒塔，可直接生产步兵和载具。
3. 前进侦察车持续披露中央战区，敌军七职业攻击编队主动向玩家战线推进。
4. 中央信标在开局 15 秒后解锁；玩家可选择消灭敌方指挥核心，或控制信标完成胜利。
5. 采集、建造、生产、科技、维修、取消、保存、载入、失败与重开均沿用正式模拟规则。

## 关卡编排

- 所有单位、建筑、目标、路径和碰撞继续位于同一平面。
- 玩家前线位于西北基地与中央信标之间；侦察单位在前，步兵和反甲居中，坦克/压制车在两翼，火炮位于后方。
- 敌军从信标东侧进入，进入玩家视野后主动推进。
- 正式 Blender 残骸、弹坑、沙袋和补给物仅作为背景陈设，不提供虚假的掩体或碰撞规则。
- 演示夹具使用额外耐久，确保交火在玩家理解界面后仍持续；正式单位配置和普通对局平衡不变。

## 实机证据

- 1280×720、高画质：七个玩家单位默认选中，六个敌方目标持续可见；连续采样存在 muzzle/projectile/impact 效果；控制台错误和警告为 0。
- 生产：堡垒坦克按钮可用，点击后进入工厂队列并显示确认反馈。
- 保存/载入：本机保存成功，按命令日志重建后确定性校验通过。
- 390×844、低画质、低动效：七单位默认选中、六敌军可见、无横向溢出，主要触控目标不小于 44px，控制台错误和警告为 0。

## 确定性验收

关卡测试验证以下契约：

- 双方各七个职业完整的混编单位。
- 玩家工厂、后勤节点和哨戒塔已联网且供电。
- 玩家初始拥有 5,200 辉晶和足够的生产带宽。
- 20 秒无输入推进后，信标已解锁、敌军已受到真实伤害、对局仍处于可操作状态。
