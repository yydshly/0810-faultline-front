# 战斗视觉反馈：表现层升级

本轮只读取既有 `shot / impact / destroyed` 事件和实体生命值，不修改伤害、射速、碰撞、寻路、视野或回放状态。

## 可读性契约

| 表现 | 触发 | 持续时间 | 低画质 / 减少动态替代 | 清理与上限 |
| --- | --- | --- | --- | --- |
| 弹丸命中 | 可见区域内的低半径、低伤害 `impact` | 约 0.34 秒 | 保留短闪、地面环和少量火花 | 高/中/低画质最多 32/24/14 个；减少动态最多 8 个 |
| 重炮爆炸 | 可见区域内的大半径、高伤害或已公开重武器来源的 `impact` | 约 0.74 秒 | 低画质取消上层火球和碎屑；减少动态保留短冲击环、焦痕与静态烟团 | 高/中/低画质最多 12/8/5 个；减少动态最多 4 个 |
| 建筑受损 | 建成建筑生命值不高于 66% | 持续到修复、摧毁或离开可见范围 | 静态焦黑结构片和单股烟 | 不进入瞬时效果队列，随实体视觉节点一起清理 |
| 建筑濒危 | 建成建筑生命值不高于 30% | 持续到修复或摧毁 | 增加第二处破损、双股烟、橙色危险环；减少动态使用稳定火芯和固定危险环 | 不改变模型根节点、碰撞体或选择范围 |
| 焦痕 / 烟 / 碎屑 / 残迹 | 重炮命中或摧毁 | 0.7–34 秒 | 低画质关闭碎屑并缩减烟团；减少动态碎屑上限为 0 | 各类型有独立上限，同时仍受全局 128 个效果上限约束 |

所有短时效果复用缓存几何和共享材质。每个效果有明确类型、生命周期和自动移除规则；同类效果达到上限时先清理最早实例，装饰效果仍可被优先淘汰。更新循环不按帧创建临时几何、材质或粒子对象。

敌军信息仍由既有战争迷雾过滤。命中和爆炸只在命中位置当前可见时生成；只有已公开的来源 ID 才能参与“重武器来源”判断，因此不会通过特效类别暴露隐藏单位种类。隐藏或离开视野的敌方建筑，其持续受损节点会随实体视觉节点移除。

开发模式新增以下画布指标：

- `presentationBallisticImpacts`
- `presentationHeavyExplosions`
- `presentationDamagedBuildings`
- `presentationCriticalBuildings`

纯函数测试覆盖建筑健康阶段、弹丸/重炮分类，以及画质和减少动态下的同类效果上限。
