# 桌面 Web 视觉金标验收

## 目标

`visual-gold-review` 是本项目的桌面第一眼质量基准。它不是完整战役，也不是纯模型展台，而是一个固定、可操作、可重复的真实游戏场景：同一镜头同时验证地图层级、建筑入口、单位比例、职业轮廓、接地阴影、阵营区分、生产状态与战斗反馈。

本阶段只以桌面 Web 为发布门槛：

| 画幅 | 质量 | 作用 |
| --- | --- | --- |
| 1440×900 | high | 主构图、资产材质与桌面 HUD 验收 |
| 1280×720 | high | 较小桌面视口的可读性与遮挡回归 |

现有移动端适配继续保留，但 390×844 不阻断本阶段交付。

## 固定内容

玩家侧必须同时出现：总部、载具工厂、主战坦克、采矿车、步枪小队、工程小队、反装甲小队。对照侧只保留少量敌方主战坦克、步枪小队和哨戒塔，避免把画面变成压力测试。地表需要包含混凝土基地铺装、连续入口坡道、主道路、矿区、少量战损和非碰撞工业道具。

## 第一眼判定

- 3 秒内能区分总部和工厂；工厂生产口必须是有纵深的暗舱，而不是贴墙黑板。
- 3 秒内能区分坦克和采矿车；采矿车货舱能表达空载、半载和满载。
- 3 秒内能区分三类玩家步兵，不依赖阅读文字或只看颜色。
- 玩家与敌方依赖大形和材质语法区分，阵营灯只作辅助。
- 所有单位与建筑在道路、铺装和土壤上都具有稳定接地关系，不漂浮、不陷地、不出现明显 Z fighting。
- 画面中功能发光面积克制；暖色入口灯、青色玩家状态灯和红色敌方状态灯职责明确。
- 固定构图下 HUD 不遮挡总部、工厂入口、玩家英雄单位或敌方对照目标。

## 运行时真值

- 评审夹具使用正式 GLB；任一正式模型加载失败必须产生可观察的 fallback/warning 指标，不能以程序模型悄悄通过。
- 同名材质不能跨资产错误共享；冷启动与重新载入不得随机改变贴图。
- 工厂门、生产指示和吊机只在生产队列的 `remaining` 实际下降时活动。
- 工地扫描只在 `buildProgress` 实际增长时活动。
- 采矿车只按权威 `cargo / cargoCapacity` 显示货物级别。
- 隐藏敌军不能通过声音、枪口 socket、特效类型或模型预加载状态泄露战术情报。

## 性能与资源记录

每个桌面画幅冷启动与重新载入各一次，记录以下开发指标：

- authored asset 请求数、成功数、失败数、fallback 标签和首个正式模型可见时间；
- renderer calls、triangles、geometries、GPU 已上传 textures；
- 材质跨 owner 复用必须为 0；
- LOD0/LOD1/LOD2/culled 数量，强制 LOD0 数量和动画节流数量；
- 活动生产建筑、工厂门、兵营门、吊机、采集头和施工扫描数量；
- 浏览器控制台 error 为 0，warning 只允许明确列入豁免的开发提示。

发布 GLB 的静态预算可用 `python tools/report_glb_metrics.py <glb...>` 生成稳定 Markdown 表；工具直接读取 GLB JSON chunk，不解码纹理，也不修改资产。

视觉金标不是压力场景，因此预算重点是稳定与可解释，不以堆满单位换取高三角面。最终 `breakthrough-demo` 仍单独承担大规模战斗压力验收。

## 证据

每次金标资产批次至少保留：

1. 两个桌面画幅的场景截图；
2. Blender 母版预览和发布 GLB 指标；
3. KTX2/语义节点合同验证结果；
4. TypeScript、定向测试、全量测试和生产构建结果；
5. 已知差距和下一批只允许解决的前三项资产问题。

## 2026-08-09 第一批验收结果

最终评审地址：`/?fixture=visual-gold-review&quality=high`。桌面专用布局使用完整 WebGL 战场宽度，经典右侧机壳在该夹具中关闭；小地图固定在左下，紧凑命令坞位于底部且不遮挡总部入口、工厂生产舱、玩家英雄单位或敌方对照目标。总部和工厂的 authored `+Z` 入口正向固定镜头，金标场景使用顺镜头主光、环境补光并关闭战术迷雾遮罩，普通对局灯光不受影响。

运行时材质修复为：带 BaseColor/KTX2 贴图的正式材质保留 GLB 的白色颜色因子；只有无贴图程序回退材质才应用运行时色板。由此避免深灰色板与 authored 贴图二次相乘造成的黑模。

## 2026-08-09 第二批桌面视觉金标验收

第二批保持首批的固定镜头、12 件资产白名单、紧凑 HUD 和权威玩法平面不变，只收口建筑中尺度表面层次与基地入口地表关系。总部/工厂的板面分割、服务结构和边缘受光比首批明确；服务地坪、入口喉道、Y 形路径、路肩与磨损标记使基地关系和入口指向明显改善。

这一批对建筑表面层次记为 `partial`：中尺度信息已达到本批目标，但总部和工厂在战略镜头下仍偏暗。下一批不再继续堆叠建筑小构件，优先收口当前更显玩具感的矿床与敌方哨塔。
