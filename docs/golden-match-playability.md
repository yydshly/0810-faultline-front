# 黄金对局可玩性收口

## 产品目标

`breakthrough-demo` 是当前默认标准难度对局。它不是模型陈列或自动交战夹具，而是一局从基地整备开始、以明确胜负结束的桌面 RTS 流程。根地址 `http://127.0.0.1:4180/` 先在 00:00 暂停并显示任务简报；存在有效突破战存档时可继续保存时的难度与进度，否则选择三档难度开始新战局。`/?fixture=default` 保留为自由经营沙盒。

## 玩家流程

| 阶段 | 代表时间 | 玩家动作 |
| --- | ---: | --- |
| 战前整备 | 00:00–00:42 | 完成卸矿、建成哨戒塔、生产首辆战斗车辆 |
| 前沿突破 | 00:42–03:42 | 选中编队，按 A 后右键推进东南防线 |
| 装甲反扑 | 03:42–06:12 | 以坦克承伤、炮兵输出，击退敌军反扑 |
| 友军增援 | 06:12–08:42 | 接应五类增援并重组终局编队；信标开放 |
| 最终决战 | 08:42–08:56 | 摧毁敌方总部，或占领中央信标 |

时间来自种子 `1949` 的代表性确定性流程。不同操作会改变实际时长，但目标区间为 8–12 分钟。

## 本轮玩家可见改动

- 根地址新增新兵、标准、老兵三档任务简报；对局内与结算页均可安全重新部署并更改难度，不会在当前回放上热改倍率。
- 根任务简报会识别有效的突破战存档，显示保存难度与作战时间并允许一键继续；恢复使用精确场景、种子和帧数校验，失败时保持 00:00 暂停并回到新局简报。
- 开局由十人自动乱战改为五人整备编队；敌方前线五人驻防，不再零秒冲锋。
- 左上任务入口常驻显示当前目标和整备进度；任务抽屉内给出下一步可执行命令。
- 三项整备已改成顺序引导：卸矿明确标注为自动执行；建塔按钮会切到防御页并定位已验证的合法区域；载具按钮会直达载具页，排队后显示剩余秒数。
- 四个以上玩家单位按兵种聚合显示数量与最低生命，命令区保持固定可用。
- 任务抽屉、帮助页和窄屏生产抽屉打开时暂停模拟；桌面常驻生产侧栏不会暂停。
- 哨戒塔、双方任务波次压制车以及玩家炮兵提前加载；开场稳定为 40/40，无阶段换模回退。
- 最终阶段闲置 180 秒后，敌军会派出一支锁定我方指挥核心的最终攻势；严重弃守可在 12–17 分钟自然失败，正确路线仍保持 8–12 分钟胜利窗口。
- 黄金对局的敌军节奏只由任务导演和显式波次控制；通用 AI 在带宽达到 80、已有待建中继或已有两座中继时不再扩建，消除了长局 48–50 座中继的失控增长。

## 验收证据

1440×900、高画质、本地根地址实测：

- 首屏加载 40/40，失败 0、重试 0；玩家与敌方开场各五类任务单位，敌军未进入首屏视野。
- 任务遮罩打开后计时从 `02:27` 等待 5.5 秒仍为 `02:27`；关闭后从 `02:28` 恢复到 `02:30`。
- 通过真实 UI 放置哨戒塔并生产侦察车，任务进入阶段 2/5；随后以雷达定位并用 A + 右键下达移动攻击，自然进入阶段 3/5。
- 新版 1280×720/high 复验：任务 1/3 时点击“定位并建造哨戒塔”会关闭暂停抽屉、切到防御页并聚焦推荐区；战场中央一次点击成功施工。完成后按钮切换为“打开载具生产”，侦察车排队期间任务显示“生产中 18 秒”，完成后自然进入阶段 2/5。
- 代表帧：开场约 295 calls / 91,220 triangles / 195 textures；前沿接战约 357 calls / 64,723 triangles / 210 textures。
- 浏览器控制台 warning/error 为 0。
- 续战浏览器验证：老兵存档返回根地址后显示保存难度与作战时间并获得初始焦点；恢复后进入老兵规范地址、继续计时并清除 `resume / resumeTick`。无参数刷新从新局 00:00 开始，不会重复自动载档。
- 失效续战验证：错误模拟刻会清除请求、保持 00:00 战术暂停、重新打开必选简报并隐藏继续入口；非突破战地址会安全清除续战参数并正常计时。

自动化质量门：32 个测试文件、315 项测试全部通过；黄金长流程在三个镜像检查点哈希一致，并于 535.95 秒以“敌方指挥核心被摧毁”结算胜利；三档均有独立哈希与长流程检查，弃守流程会以“指挥核心被摧毁”自然失败。TypeScript、42/42 GLB 资产合同（其中 17 件有纹理资产满足 KTX2 合同）与 35 modules 生产构建均通过。唯一构建提示仍是 Three 主包压缩前 549.65 kB，超过 500 kB 提示线但不影响运行。

## 边界

本轮只以桌面 Web 为发布面，不以手机布局或手机性能作为阻塞条件。续战入口复用既有存档格式；资产继续使用现有原创 42 件 Blender/GLB 资产族，本轮没有新增模型精修波次。
