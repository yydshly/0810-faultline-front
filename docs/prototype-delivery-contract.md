# 《断层战线》可玩原型交付契约

Entry mode: continuation / reference-led revision  
Request revision: 6  
Target user and context: 喜欢经典基地建造 RTS 的桌面玩家；在浏览器中快速验证操作、战场可读性与基础闭环。  
Desired first impression: 一眼看出这是统一、原创、可操作的近未来 RTS 战场，而不是文档页面或静态概念图。  
Visual ambition: Immersive  
Experience architecture: Spatial Stage  

## 体验架构

- Scene base: Three.js WebGL；平面 XZ 战场，所有玩法锚点 Y=0。
- Scene persistence: 战场贯穿启动、选择、建造、采集、交战与结算；暂停/结算只覆盖前景，不卸载战场。
- Foreground control model: 桌面采用经典 C&C 式右侧固定指挥栏，依次承载资源状态、雷达、系统动作、四类生产页签和纵向建造队列；当前选择/单位命令使用战场底部窄条；任务和帮助为按需叠层。
- State-to-scene mapping: 未选择、已选择、移动命令、攻击、维修、采集、建造预览、合法/非法放置、可见/已探索/未知区域、雷达在线/离线、研究、取消退款、低电、断网、回放、胜利、失败都同时改变场景反馈和 HUD。
- Mobile transformation: 1180px 以下右侧指挥栏转为可关闭叠层，760px 以下转为命令坞上方工作表；雷达、资源与四类页签仍属于同一控制上下文。移动端只验证布局与基础点按，不承诺完整触控 RTS 操作。
- Fallback: WebGL 不可用时显示可读的产品说明、控制说明和明确能力边界；不伪装为可玩状态。

## 约束

- Visual constraints: 操作布局与信息节奏严格参考《红色警戒 2 / 尤里的复仇》的经典右侧指挥栏、雷达、四类生产页签和纵向队列；地图、模型、图标、标志、字体、纹理与声音全部原创。继续使用石墨钢、琥珀玩家色、青色功能灯与固定正交 45°/55° 镜头。
- Information constraints: 首屏只突出战场、资源/电力/带宽、当前选择、当前目标；调试数据不常驻。
- Operation constraints: 左键选择/框选，Shift 追加，右键情境命令（工兵对受损友军为维修），A 移动攻击，S 停止，Ctrl+数字编组，数字召回，B 建造，R 旋转，Escape 取消/关闭；研究、取消/退款、存档与回放必须有可见语义按钮和状态反馈。
- State constraints: 所有付费操作必须先校验并给出原因；资源、电力、带宽、生命、网络和胜负状态必须可见。
- Environment constraints: 无后端、无登录、无外部服务、桌面键鼠优先；本轮实现当前版本内的单槽本地存档与确定性回放，不承诺跨版本存档兼容；不实现正式联机、航空和 T3。
- Supported theme: 单一战术暗色主题；浅色主题不在本原型范围。
- Supported locale: 简体中文；控件宽度需容纳当前中文标签。
- Motion: 尊重 prefers-reduced-motion，移除非必要过渡、镜头缓动和脉冲动画。

## 主要旅程

打开对局 → 识别双方基地与任务 → 选择/框选己方单位 → 移动或攻击 → 采集辉晶 → 建造反应堆/后勤节点 → 生产单位 → 摧毁敌方核心或占领信标 → 查看结算 → 重开。

## v0.2 范围修订

- 导航：静态障碍采用确定性的网格 A*，单位保持现有局部避让；相同种子与命令必须得到相同路径和状态哈希。
- 编队：多选移动时围绕目标生成稳定槽位，避免所有单位挤在同一点；槽位分配按单位标识稳定排序。
- 工兵：对受损友军右键下达维修命令，接近后持续消耗资金恢复生命，满血、目标失效或资金不足时安全结束。
- 炮兵：命中点产生有衰减的范围伤害，并保留清晰的弹道与命中反馈。
- AI：以经济、集结、进攻、防守、恢复等可检查状态驱动扩张与混编进攻；状态切换带最短驻留时间，避免每帧抖动。
- 存档/回放：保存初始种子、关卡夹具、外部命令日志与当前 tick，通过重新模拟恢复；拒绝版本不兼容或损坏数据。

## v0.3 范围修订

- 战争迷雾：双方分别维护确定性的当前可见与历史已探索网格；友军视野揭示地形，离开视野后保留已探索但不保留实时敌军位置。
- 雷达：完工、联网且供电的指挥核心/后勤节点提供扩展情报；低电或断网时扩展范围立即失效，基础单位视野仍可用。
- 情报边界：玩家不能选取或直接攻击当前不可见敌军，小地图不泄露隐藏敌军；敌方 AI 的输入同样只包含其当前可见目标。
- 科技：在指挥核心研究“高效精炼”“复合装甲”“信号增幅”三项当前版本科技；研究付费、排队、完成和效果必须确定性且可回放。
- 取消退款：施工、生产队首和当前研究可取消，统一返还 75% 基础费用；同一项目不能重复退款，带宽和队列状态立即恢复。
- 表现：场景用轻量迷雾层区分未知、已探索和当前可见；HUD 同时提供雷达状态、研究进度、取消动作及不可用原因，WebGL fallback 仍保留可读情报状态。

| 控制密度 | 研究使用现有卡片体系，取消只在当前选择可取消时启用 | 不为每个队列增加常驻浮层 | 研究、进度、完成、取消和退款原因均可由语义按钮获得 |

## v0.4 范围修订

- 防御工事：新增“哨戒塔”和“重炮塔”两种可建造建筑，继续使用现有石墨钢、琥珀阵营色和青色功能灯的程序化模型语言；不引入外部资产或复制既有商业 RTS 造型。
- 权威战斗：防御塔的索敌、射击、弹道、范围伤害、冷却和摧毁结果都由固定步进模拟决定；表现层只消费已解析事件。
- 情报与能源：防御塔只能攻击本阵营当前可见目标；未完工、断网、未供电或电力比例低于阈值时停止射击，恢复条件后按确定性规则继续。
- 战术差异：哨戒塔以高射速压制步兵和轻甲；重炮塔以较慢射速、明确弹道和小范围伤害对付重甲与建筑，二者不存在无条件最优替代。
- AI：敌方在防守压力和经济许可下按确定性优先级部署防御塔，且仍遵守建造覆盖、资源、供电和可见性规则。
- 音频：新增无外部音频资产的 Web Audio 反馈层，为命令接受、射击、命中、摧毁、采集入账、建造/生产/研究完成和警告分配有限声部；必须在用户手势后解锁、限制并发、释放节点并可一键静音。
- 无障碍与降级：所有有意义声音保留现有视觉反馈；静音状态可见并持久化。Web Audio 不可用时显示明确不可用状态，但不影响核心玩法或 WebGL fallback。
- 存档边界：防御塔属于权威状态并进入哈希/回放；静音属于本机偏好，不进入确定性模拟或回放。

| 决策 | 方向 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 模型一致性 | 两种塔共享现有混凝土底座、装甲分层、阵营色条和供电灯，仅用炮组比例区分职责 | 不新增独立美术风格或纹理下载 | 缩放到默认正交镜头时仍能区分哨戒与重炮，但一眼属于同一阵营建筑族 |

## v0.5 UI 视觉修订

- 构图：保持 WebGL 战场铺满视口；桌面只常驻紧凑顶部资源脊柱与一体式底部指挥台（雷达 / 当前选择 / 部署终端），任务和系统工具进入可关闭叠层，不再让多个同权重大面板包围战场。
- 层级：第一眼先读战场与当前交战，其次读辉晶/电力/带宽和当前选择，任务说明、系统工具、帮助与次级状态降低视觉权重。
- 部署终端：建造、部队、科技改为同一终端内的三类语义标签页；每次只展示一个操作集合，保留所有费用、不可用原因、进度、取消与焦点语义。
- 密度：移除常驻快捷键墙，改为少量关键热键提示和紧凑系统工具；正文与控件不再使用难读的超小字号，中文标签优先于装饰性英文。
- 材质：采用不透明度更高的石墨装甲板、克制的边缘高光和少量琥珀状态条；青色只表示数据/联网，琥珀只表示玩家操作/选中，红色只表示危险/拒绝。
- 深度：通过轮廓、明暗和局部阴影表达前景层级，减少大面积毛玻璃、泛光、斜切和同时发亮的边框；场景中心不叠加装饰噪声。
- 响应式：1180px 以下将部署终端切换为可关闭叠层并保留底部选择/命令，760px 以下将终端变为命令坞上方的工作表；390px 中文标签不截断关键含义。
- 无障碍：保留语义按钮、标签页角色、焦点可见、Escape/焦点返回、ARIA 状态与 reduced-motion；视觉改造不改变模拟、回放、存档或输入规则。

## v0.6 红警 2 / 尤里复仇参考修订

- 指挥栏：桌面右侧固定约 300px 的独立控制表面；战场不被其遮盖。顶部为阵营/资源与电力状态，中段为雷达，下方为系统工具、生产页签与队列。
- 生产分类：按原作信息架构拆分为“建筑 / 防御 / 步兵 / 载具”四页；科技并入防御/军备页，不再单独占据一级标签。
- 队列反馈：生产卡保留价格、锁定原因、排队数字、研究/施工进度和取消操作；当前页签及生产状态在低饱和金属框架中高对比显示。
- 战场构图：移除灰盒网格感，增加确定性地表纹理、道路边线、基地铺装、资源侵蚀圈、战场残骸与边缘地标；所有可移动玩法仍严格位于 Y=0 平面。
- 模型家族：建筑使用共享装甲底座、分层墙板、屋顶设备、门洞、管线和角撑；车辆使用共享底盘、履带/轮组、装甲斜面、炮塔接口和阵营识别条；步兵、资源与信标保持默认镜头距离下可辨识轮廓。
- 原创边界：只参考右侧侧栏、雷达、四生产类别、纵向队列和经典 RTS 操作节奏，不复制 Westwood/EA 的图像、文字商标、肖像、音频或模型造型。
- 性能边界：新增地表纹理使用确定性 DataTexture；重复装饰共享几何与材质；不引入外部大体积 3D 资源，不改变固定步进和权威状态。

- 关卡、模拟、渲染、输入、HUD 分层源文件。
- 自动化测试与构建命令。
- 确定性寻路、AI 规划和回放/存档模块及对应回归测试。
- 确定性可见性、科技与取消退款模块/规则及对应回归测试。
- 防御塔权威战斗与程序化音频反馈模块及对应回归测试。
- 浏览器验收记录和最终交接说明。
- 现有完整设计文档和视觉基准图保持不变并继续作为规范来源。

## Authorization

Autonomy authorization: 用户明确说“继续”，结合前一轮完整设计稿，授权在既定原型范围内直接实施和验证所有可逆本地变更，无需重复确认。  
User-decision boundary: 只有正式联网、付费服务、发布部署、引擎迁移或改变产品阵营/核心机制才需要新决定。  

## Observable completion criteria

- npm run dev 可打开唯一规范 URL；npm run build 和 npm test 通过。
- 1440×900 桌面浏览器中战场、HUD、选择、移动、采集、建造、生产、战斗、结算可观察且无控制台错误。
- 1024×768 与 390×844 不出现关键控件不可达、文字遮挡或战场完全被面板覆盖。
- 键盘焦点可见；Escape、重开和主要按钮可使用；reduced-motion 不隐藏信息。
- WebGL 能力不可用时存在明确、可读的边界界面。
- A* 对直达、绕障、不可达和不同净空半径给出稳定结果；多单位移动形成可观察编队。
- 工兵维修会消耗资金并恢复生命；炮兵范围伤害具有距离衰减且不误伤同阵营单位。
- 相同种子与命令日志回放到同一 tick 后状态哈希一致；损坏或版本不兼容存档给出可恢复提示。
- AI 状态与决策可在确定性夹具中复现，能够在经济、集结、进攻、防守和恢复之间合理转换。
- 同一状态下双方可见/已探索网格稳定一致；移出视野的敌军从场景、拾取和小地图消失，但已探索地形保持。
- 雷达扩展仅在建筑完工、联网且供电时生效；信号增幅研究完成后按定义扩大情报范围。
- 三项科技均正确扣费、推进、完成并应用效果；取消施工/生产/研究只退款一次且退款额为基础费用的 75%。
- AI 不读取战争迷雾外的实时敌军；新增研究与取消命令通过版本化回放后状态哈希一致。
- 两种防御塔只攻击当前可见敌军，遵守射程、冷却、阵营、供电和联网条件；重炮溅射不误伤同阵营单位。
- 音频只在用户手势后启动，可静音并持久化；快速事件受节流和并发上限约束，Web Audio 不可用不阻断玩法。
