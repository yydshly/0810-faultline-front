# 核心建筑实体受损波次

## 结果

玩家与敌军的总部、载具工厂现已把两级实体破损直接嵌入各自正式 GLB。场景不再只依赖烟雾和警戒环表达低生命：墙体缺口、屋顶塌陷、弯折装甲与瓦砾会由权威生命值切换，同时继续保留原有烟、火与生命条反馈。

- `damage_visual_damaged`：局部缺口、弯折板件和少量瓦砾。
- `damage_visual_critical`：自包含的严重塌陷、外翻板件和更多瓦砾。
- 两个阶段互斥，任何建筑同一时刻最多显示一套 3 primitive 模块。
- 没有新增纹理或材质槽；全部复用资产原有材质。
- 资产生成、预览、哈希和回退记录见 [核心建筑专属受损资产](core-building-damage-assets.md)。

## 权威状态映射

| 条件 | 实体破损层 | 其他反馈 |
| --- | --- | --- |
| `buildProgress < 0.995` | 两层均关闭 | 施工三阶段继续接管表现 |
| `hp / maxHp > 0.66` | 两层均关闭 | 正常建筑 |
| `0.30 < hp / maxHp <= 0.66` | 仅 damaged | 伤痕与单层烟雾 |
| `hp / maxHp <= 0.30` | 仅 critical | 双层烟雾、火芯与警戒标记 |
| 摧毁开始 | 两层立即关闭 | 进入既有建筑爆炸/倒塌链路 |

运行时版本为 `authored-building-damage-v1`。显隐只读取模拟状态，不写回生命、碰撞、占地、导航、生产或回放。敌军建筑仍必须出现在玩家的 `visibleEnemyIds` 中才会创建场景实体；正常对局的战争迷雾和事件披露边界没有改变。

材质热加载会重建 visual，并从当前权威生命值重新求阶段；LOD 切换只恢复该阶段所需的唯一语义根。指标 `presentationAuthoredBuildingDamageOverlaps` 必须始终为 `0`。

## 桌面评审夹具

- `/?fixture=building-damage-review&quality=high`
- `/?fixture=building-damage-review-reduced&quality=low`

夹具只请求四件核心建筑资产。玩家与敌军各有一座总部和一座工厂处于 52% 生命，另四座处于 22% 生命。坐标按 45° 相机的屏幕轴编排：相同 `x + z` 形成真正的横向对照行，因此上排是 damaged、下排是 critical，而不是世界矩形投影后的斜线。

该夹具使用紧凑视觉评审 HUD、固定 56 米视高，并仅在评审场景关闭雾层和直接披露四座敌军建筑。它不再生成用于探视的工兵，所以画面没有额外单位，也不会多下载第五件资产。正常关卡不使用这条评审例外。
