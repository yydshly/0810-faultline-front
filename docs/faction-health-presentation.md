# 阵营识别与生命条呈现合同

本轮只改变表现层，不改变模拟、寻路、攻击判定或战争迷雾。

## 阵营色

- 玩家阵营：蓝色主识别色，亮蓝用于战术标记、选择圈、生命条边框和雷达。
- 敌对阵营：红色主识别色，亮红用于同一组战术反馈。
- 中立阵营：灰色，不与资源金色和生命值颜色混用。
- `factionVisual(factionId)` 接受任意稳定字符串。未来新增势力可直接获得确定性的紫、金、绿、品红或青绿色，不需要在 HUD、Canvas 和 Three.js 中分别硬编码。

当前模拟仍定义玩家、敌军和中立三类队伍；展示层已经解除只能识别两种颜色的限制。正式增加第三个可玩势力时，只需扩展模拟队伍数据并为其指定视觉令牌。

## 战场标记

每个已经通过情报披露、且当前可见的单位或建筑都有一个小型阵营菱形标记。标记不会为战争迷雾中的敌军创建，因此不构成情报泄漏。

所有标记使用两个动态实例批次：一个深色底板批次和一个按实例着色的阵营色批次。实体数量增加时不会按单位线性增加绘制批次。

## 生命条

- 生命值填充：健康为绿色、警戒为黄色、危急为红色。
- 所属阵营：由生命条外框表达，玩家为蓝框、敌军为红框。
- 完整生命值默认只在选中时显示；受损实体会持续显示。
- 底板、阵营框和填充全部进入同一透明渲染队列，并用 20 / 21 / 22 的顺序绘制，避免黑色底板覆盖彩色填充。

## 资产边界

现有 GLB 保留作者制作的 PBR 材质，不在运行时粗暴乘色，避免 KTX2 贴图变黑或失真。若后续要求“车体装甲本身可切换任意势力色”，正确做法是在 Blender 资产合同中加入独立的阵营色遮罩或可重映射材质槽；当前战术标记系统可在该资产升级前稳定承担敌我识别。
