# 突破战三档难度、部署与续战入口

更新时间：2026-08-10

## 玩家路径

- 无显式 `fixture` 的根地址先打开任务简报，标准难度默认选中；模拟、镜头与快捷键在 00:00 暂停。
- 当前浏览器若存在有效的突破战存档，简报会优先聚焦“继续上次战况”，并显示保存时的难度与作战时间；“开始新战局”仍保留为独立入口。
- 难度卡支持点击、方向键、Home/End；初始简报不能用 Escape 跳过，必须选择并开始部署。
- 开始后使用独立的确定性场景地址重新加载对局：新兵 `breakthrough-demo-cadet`、标准 `breakthrough-demo`、老兵 `breakthrough-demo-veteran`。
- 对局内系统工具显示当前难度。重新选择会明确重新部署，不在运行中的回放上热改倍率。
- 胜败结算可按当前难度再次部署，也可返回难度简报；取消更改会恢复原结算页。
- 显式评审和深链地址直接进入，不弹出首局简报，不影响自动化夹具。

## 继续上次战况

- 简报只读取经过回放格式严格校验、且属于可玩突破战三档之一的存档摘要；损坏、过期或其他评审/沙盒存档不会显示继续入口。
- 点击继续后先跳转到存档的精确 `fixture + seed`，再在首帧前暂停并按确定性命令记录重建，不会在当前难度场景中热切换。
- 自动恢复使用一次性 `resume + resumeTick` 校验；成功或失败都会清除标记，因此刷新页面不会重复载入旧档。
- 若存档在跳转期间被替换、删除或与请求不一致，页面会停在 00:00 的必选简报，隐藏继续入口并提示开始新战局，不会静默进入错误状态。
- 手动载入仍保持原有场景绑定规则；成功后地址中的场景与种子会同步到实际存档。

## 三档曲线

| 难度 | 定位 | 关键差异 |
| --- | --- | --- |
| 新兵 | 首次指挥 | 我方初始部队更耐久、任务敌军较弱、增援更多、最终攻势在 240 秒无推进后到达 |
| 标准 | 推荐黄金对局 | 保留既有约 9 分钟代表流程，经济、前沿反扑、增援与最终攻势保持均衡 |
| 老兵 | 高压 | 敌军更坚韧，反扑与增援阶段更短，最终攻势在 120 秒无推进后到达且规模更大 |

所有差异都来自 `src/game/difficulty.ts` 的只读配置。场景地址进入回放与存档身份，因此同一种子、同一难度、同一命令序列仍产生相同哈希；跨难度存档会按既有场景绑定规则拒绝载入。

## 验证结果

- 难度配置与别名契约 25 项通过。
- 关卡确定性与长流程 35 项通过：三档均保持单一玩法平面与镜像哈希一致。
- 新兵正确路线在 8–12 分钟内自然胜利；标准既有自然胜败继续通过；老兵弃守在 9–14 分钟自然失败，部署前 120 秒不会偷袭。
- 桌面浏览器验证：初始简报 00:00 持续暂停；方向键可从标准切到新兵；Escape 不会关闭必选简报；选择老兵后进入其规范地址并正常计时。
- 对局中打开难度简报时，计时在 00:10 保持不变；取消后恢复到 00:12。胜利结算可进入难度简报，取消后恢复原结算页。
- 存档恢复实测：根简报显示“老兵难度 · 00:01”并把焦点落到继续入口；恢复后进入老兵规范地址并继续计时，地址中的一次性标记被清除。随后刷新从 00:00 新开局而非重复载档。
- 失效 `resumeTick` 实测会清除请求、停在 00:00 必选简报并显示恢复失败提示；`default` 等非突破场景会直接忽略并清除恢复标记。整组浏览器流程无 warning/error。

## 边界

本阶段只完善桌面 Web 的完整选择、继续存档与重部署路径，没有新增资产、修改导航、改变存档格式或承诺手机端验收。旧 `breakthrough-demo` 仍是标准难度，旧标准存档不需要迁移。
