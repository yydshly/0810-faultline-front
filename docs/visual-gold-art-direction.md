# 桌面 Web 视觉金标 v1

## 用途与来源

`assets/reference/visual-gold-web-v1.png` 是项目内部的原创战场艺术方向参考图；`assets/reference/visual-gold-buildings-v1.png` 是同一方向下的总部/载具工厂多视图参考。两者均由 OpenAI 图像生成能力于 2026-08-09 生成，只用于统一色彩、体量、轮廓、入口可读性、接地感和桌面战略镜头下的信息密度；运行时不会加载这些图片，也不会从图片中提取网格、贴图或第三方资产。

参考提示明确排除了《红色警戒》《命令与征服》及其他商业游戏中的具体阵营、单位、建筑、标志、图标和界面设计。目标是原创的 1990 年代末至 2000 年代初工业军事 RTS 视觉语法，而不是复刻原作资产。

## 金标方向

- 玩家阵营：灰绿实用主义装甲、深灰结构、少量琥珀色功能识别和暖色作业灯。
- 敌方阵营：暗铁与氧化红，轮廓更尖锐、顶部信号更克制。
- 建筑：从 3/4 俯视能一眼看出功能；总部强调通信与指挥层级，工厂强调真实纵深的生产舱、门框和连续坡道。
- 车辆：优先识别车首、履带/轮组、炮塔或采集机构，不依赖小于战略镜头可见阈值的零碎细节。
- 步兵：步枪、工程、反装甲三种职业必须依靠 0.35–0.60 米级轮廓差异识别，而不是只靠颜色。
- 地表：灰烬土、混凝土铺装、磨损道路和矿区形成层级；单位脚下保持干净，并以接触阴影建立重量。
- 灯光：单一主方向光加环境补光；暖色发光只说明入口、作业或状态，避免全身霓虹。

## 桌面验收画幅

- 主画幅：1440×900，桌面高画质。
- 次画幅：1280×720，桌面高画质。
- 本阶段不以手机端作为视觉验收门槛；保留现有响应式代码，但不为移动端牺牲桌面构图。

## 使用边界

参考图不是“完成效果截图”，也不是模型逐像素目标。最终资产必须来自项目内 Blender 程序化生成与人工可编辑母版，并继续满足尺寸、轴向、接地、语义 socket、材质、KTX2 和运行时性能合同。
